# CEFR Vocabulary Sources

Dango uses a vocabulary list (`user_prompts_full_vocab.txt`) derived from the following resources, distributed by [Open Language Profiles](https://github.com/openlanguageprofiles/olp-en-cefrj).

- **A1-B2: [CEFR-J Vocabulary Profile v1.5](https://github.com/openlanguageprofiles/olp-en-cefrj/blob/master/cefrj-vocabulary-profile-1.5.csv).** Compiled by Yukio Tono, Tokyo University of Foreign Studies; copyright belongs to Tono Laboratory at TUFS. Research and commercial use are permitted without charge with proper citation. 
- **C1-C2: [Octanove Vocabulary Profile v1.0](https://github.com/openlanguageprofiles/olp-en-cefrj/blob/master/octanove-vocabulary-profile-c1c2-1.0.csv).** Created by Octanove Labs; licensed under [CC BY-SA 4.0](https://creativecommons.org/licenses/by-sa/4.0/). Redistribution and adaptation are permitted with attribution, a license link, and an indication of changes.
